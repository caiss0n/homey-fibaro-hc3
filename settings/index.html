Fibaro Home Center 3 Settings

Setup Instructions

  1. Enter the local IP address of your HC3 (e.g., 192.168.1.100). You can find it in the HC3 web interface under Settings → Network.
  2. Enter a HC3 username and password. The user needs permission to control devices and read states.
  3. Click Test Connection to verify, then Save Settings.

Note: The connection uses plain HTTP on your local network. Use a dedicated HC3 user with only the permissions this integration needs.
